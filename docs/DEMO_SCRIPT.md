# 시연 영상 촬영 대본 (약 3분, 소리 없는 화면 녹화 + 자막)

이전 프로젝트와 같은 방식입니다: 소리 없이 화면만 **장면별로 따로 촬영**하고, 편집 프로그램(Clipchamp 등)에서 이어 붙이며 자막을 넣습니다.
장면마다 따로 찍으면 실수해도 그 장면만 다시 찍으면 됩니다.

## 촬영 전 준비

1. **이전에 띄운 로봇과 수집기를 모두 종료합니다** (각 터미널에서 `Ctrl+C`). 시연 실행기는 5021~5026, 8000 포트가 쓰이고 있으면 시작하지 않고 알려 줍니다.
2. 터미널에서 실행합니다. 시작할 때마다 시연용 DB를 새로 만들어서 이전 알람이 섞이지 않습니다 (평소 `data/factory.db`는 건드리지 않음).

   ```bash
   python tools/demo.py
   ```
3. 브라우저에서 http://127.0.0.1:8000/ 을 엽니다. **전체 화면(F11)** 으로 하면 북마크 막대와 다른 탭이 안 찍힙니다. 이메일이나 개인 탭이 보이지 않게 하세요.
4. **시작하고 40초쯤 기다립니다.** 상자가 팔레트에 4개 쌓여야 이동 로봇(AGV)이 움직이는 장면을 찍을 수 있습니다.
5. 화면 녹화 도구: Windows는 `Win+G`(게임 바)나 Clipchamp의 화면 녹화를 쓰면 됩니다. 해상도는 1920x1080, 소리는 끕니다.
6. 알람 확인자 이름은 가명(예: `홍길동`)으로 넣습니다.
7. **한 번 연습으로 돌려 보세요.** 시연이 끝나면 `q`로 종료하고(모두 꺼짐) 다시 `python tools/demo.py`로 처음부터 시작할 수 있습니다.

시연 실행기 명령: `k N` 전원 끄기, `r N` 전원 켜기, `f N` 과열 시작, `d N` 응답 지연, `s` 상태 보기, `q` 종료 (N은 1~6).

## 장면별 촬영 팁

- **장면 2(AGV)**: 시작하고 약 40초 뒤부터 AGV가 움직입니다. 화면 아래 출하장 카드의 "AGV" 상태가 "팔레트로 이동 → 적재 중 → 출하 운반 → 하역 중"으로 바뀌는 것도 같이 담으면 좋습니다.
- **장면 4**: 명령을 입력하는 터미널 창과 브라우저가 한 화면에 보이면 "내가 끊었다"는 것이 전달됩니다. 창을 반반으로 나눠 찍거나, 터미널은 따로 짧게 찍어 두었다가 편집에서 겹쳐도 됩니다.
- **장면 5**: `f 5` 입력 후 이상 정지까지 약 15~25초 걸립니다. 그 사이 카메라는 5번 로봇 쪽으로 천천히 돌리고, 정지하면 알람 표로 스크롤합니다. 너무 길면 편집에서 줄입니다.
- 한 장면은 짧게(10~30초) 찍고, 자막은 한 번에 한두 줄만 넣어 글자를 크게(28pt 이상) 합니다.
- 장면 사이는 0.3~0.5초 페이드 전환이면 충분합니다.
- 소리가 없으므로 **움직임이 보이는 시점에 자막이 먼저 나와야** 합니다 (자막 먼저, 화면 변화는 그 뒤).

## 끝난 뒤

- 시연 실행기에서 `q`를 입력하면 로봇과 수집기가 모두 꺼집니다. (창을 그냥 닫으면 일부가 남을 수 있습니다. 남았다면 `s`로 확인하거나 터미널에서 `Ctrl+C`를 누르세요.)
- 시연이 만든 파일은 `data/demo.db`(시연용 DB)와 `data/demo_logs/`(로봇과 수집기 출력)뿐이고, 지워도 됩니다.
